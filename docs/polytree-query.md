# 整数 PolyTree 点定位（Unreleased）

`PolyTree64::locate(point, limits=) -> Result[TreePointLocation64, ClipError]` 查询已有整数树。点每轴必须在 ±1_000_000_000 内，包含端点。空树返回 Outside，仍检查查询点和限制参数。

| 结果 | 含义 |
| --- | --- |
| `Outside` | 不在任何轮廓内部或边界上 |
| `Inside(node)` | 最深严格包含节点，奇数深度，属于填充区域 |
| `InHole(node)` | 最深严格包含节点，偶数深度，属于孔洞 |
| `OnBoundary(nodes)` | 所有命中轮廓的节点，每个节点一次，顺序不保证 |

外轮廓 [0,0]—[20,20]、孔洞 [4,4]—[16,16]、岛 [8,8]—[12,12] 中，(2,2)、(6,6)、(10,10) 分别返回深度 1 的 Inside、深度 2 的 InHole、深度 3 的 Inside；(4,6) 单独返回孔洞边界。边界优先于内部；两个轮廓仅顶点接触时可同时命中。无边界命中而发现同深度多个严格包含节点时返回 ExecutionFailure，不任选一个。

实现直接迭代私有节点数组，复用精确叉积、点在线段和半开射线规则，使用既有深度；不复制整棵树、不重建包含关系、不递归、不用浮点、epsilon、索引或缓存。最坏线性访问全部轮廓顶点；没有索引查询性能承诺。

每次公开调用独立建账。`max_input_paths` 限制树轮廓数，`max_input_vertices` 限制所有轮廓的顶点总数；查询点不计作路径或轮廓顶点。防溢出的规模预检后直接使用受控树数据，不重复验证坐标与拓扑。合法的大树也可能被本次较小限制拒绝。默认内部预算不变，私有注入账本的限制和历史用量保持权威。

计费覆盖规模与节点访问、边访问、边界数组、数组槽、节点视图、深度矛盾检查所用的 Map 及结果，分配前收费且不退款。所有错误使用 PolyTreeQuery，路径和顶点索引均为 None，不把内部节点索引当作原始输入。预算失败不返回部分列表，不修改树或跨调用保存状态。

返回节点沿用不可变视图；OnBoundary 每次返回独立数组。修改该数组或 `contour()` 返回的副本不影响树及后续查询。仅支持整数树的单点定位，不包括小数树、批量点、最近边距离、空间索引、拓扑修复或演示。历史参考数据不构成本入口的执行证据。
