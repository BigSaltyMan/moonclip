# 显式轮廓简化与退化报告

`simplify_paths` 与 `simplify_paths_d` 只由调用者显式调用，Boolean、Offset、Stroke 不会自动启用它。选项构造 `SimplifyOptions::new(epsilon=0.0, mode=Closed)`；非法 epsilon 由运算入口返回 InvalidInput，有限但平方或缩放无法表示时返回 NumericFailure。负零按零处理。结果保留路径数量、位置、空路径及所有退化结果；数组访问器每次返回独立副本，内层路径也不共享。

## 距离、候选与顺序

先删除连续重复位置，Closed 再删除末尾重复首点；Open 保留返回起点的路线。epsilon=0 仅做这次无损整理，保留普通共线点，不运行上游零阈值分支。这是 MoonClip 自有契约；224 条独立参考全部采用正 epsilon。

正阈值采用锁定 Clipper2 2.0.1 的 SimplifyPath 模板顺序，并非 RDP。整理后不足四点直接保留。每个候选计算到两个邻点所在直线的垂直距离平方，直线不是线段。邻点重合时距离为零。固定公式是 `(a*d-c*b)^2/(c*c+d*d)`，先算有界 Int64 差再转 Double，不以整数叉积替换公式。距离平方大于 epsilon 平方时继续扫描；相等进入删除判断；相邻候选只有严格更小时才替换当前候选。删除后按固定顺序重新计算邻点距离，按原索引收集保留点。所有距离中间结果检查有限性。

Open 的两个端点不会被局部删点移除；完全折返可能留下两个相同端点，二者均保留。最终重复点清理只对 Closed 执行。Closed 接缝参加局部选择；不旋转起点、不反转路径、不排序路径。反向输入分别执行，不承诺两种候选遍历得到同一保留点集合。

## 报告

| 访问器 | 含义 |
| --- | --- |
| paths() | 完整有序结果；不筛掉退化路径 |
| removed_per_path() | 每条原始路径点数减最终点数，含两次约定整理及局部删除 |
| removed_vertices() | 上一数组的总和，调用方后续过滤不计入 |
| input_degenerate_indices() | 首次整理后、局部删除前已经退化的原始路径索引 |
| degenerate_indices() | 最终退化的原始路径索引 |
| collapsed_indices() | 最终退化且最初不退化的索引 |

索引递增且不重复。Open 至少两个不同位置才有效，折返本身仍可有效；Closed 至少三个不同且非全共线的位置才有效。用精确叉积检查，不能按有向面积零删除蝴蝶形自交。上游可能将闭合轮廓删到两个点，保留并报告，不恢复原轮廓、不改 epsilon、不补点。

报告仅说明结构退化，不证明拓扑正确。简化不保证孔洞、窄通道、自交关系保持不变，epsilon 不是全局 Hausdorff 距离或面积变化上限，也不保证全局最优。需要区域或孔洞树时，调用方检查报告，明确选择拒绝、保留或过滤，然后实际调用 offset_polygons 或 boolean_tree；不能沿用旧孔洞树。

## 小数网格

Precision 支持0—6，默认3。epsilon 使用原坐标单位，epsilon_grid=epsilon*10^precision 保持 Double，不提前取整数。PointD 原始值与选定网格范围、半整数远离零量化、不同原始位置新合并的诊断、全局首次位置索引及原单位精确解码继续沿用 [decimal.md](decimal.md)。零阈值同样先量化。

唯一操作专用区别：本入口允许原有闭合退化路径，交给报告；现有 BooleanD/OffsetD/StrokeD 不放宽。input_degenerate_indices 描述所选网格，不能据此断言原始 Double 轮廓也退化。输出恰为整数坐标除倍率，零统一为正零。

## 累计预算与失败

同一个 CallBudget 贯穿原始预检、量化/整理、工作数组、候选访问、结果收集、两次分类和最终报告。默认 InputPaths10000、InputVertices100000、InternalNodes500000、ScanWork5000000 不变。原始额度在去重前检查，空路径计路径数；剩余额度相减防累计溢出。私有入口允许精确预算测试，公开调用不共享可变状态。

| 项目 | 逻辑节点收费 | 工作收费 |
| --- | --- | --- |
| 输出/统计容器 | 五个数组各1 | 路径汇总各1 |
| 初始整理及最终闭合清理/开放快照 | 每数组1、每保留点槽1 | 每输入点1 |
| flags、distances | 两数组2、每个索引各两个槽 | 每次距离更新1 |
| 邻点寻找 | 不另分配索引数组 | 每个实际访问的标记1，删除标记也计入 |
| 候选比较扫描 | 0 | 每次判断1 |
| 局部结果收集 | 数组1、每输出点槽1 | 每原索引1 |
| 报告 | 每路径两个槽、每索引一个槽；末尾报告及返回对象共2 | 每分类访问1、每汇总/索引1，最终构建1 |
| 小数转换 | 沿用十进制预检、全局索引、量化和输出收费，末尾D对象1 | 同一剩余额度，末尾1 |

不可变 Point64 可复用；临时数组释放不退款。数组分配前收费，候选跳过和距离重算也收费，不只按成功删点计费。输出或报告最后一步仍可能失败，返回 Err，不发布部分数组或报告，源输入不变，下一调用重新建立预算。访问器在调用后生成的副本属于调用方成本。局部算法不承诺任意输入线性工作量。

## 证据范围

72 项功能测试分布为12参数/零阈值、20固定选择、12统计、16数值/预算、12小数/隔离/组合。224 条独立正阈值参考为80 Integer、144 DecimalGrid；比较完整顺序、所有统计和索引，允许短路径，不使用 Boolean 面域输出验证或环起点归一化。真实运行器只编译输入、参数、哈希；预期只进入测试。C++统计由适配器独立计算，上游模板只提供简化几何。
