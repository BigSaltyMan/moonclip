# 整数矩形窗口裁剪（Unreleased）

## Unreleased：闭合区域窗口裁剪

`rect_clip_polygons(rect, paths, fill_rule=, limits=)` 返回整数平铺闭合区域，默认 EvenOdd，也支持 NonZero。多条轮廓作为同一个填充区域求值，每条末点隐式连接首点，不要求重复首点；孔洞、重叠、自交及退化输入沿用 Boolean 语义。仅点或线接触不产生填充区域。输出可含孔洞，沿用 Boolean 的方向、共线清理和顺序约定，不保证保留原始顶点数、起点或轮廓排列。输入与输出隔离，失败不返回部分区域。

`rect_clip_lines` 解释独立开放路线并返回有序开放片段；本入口将窗口作为内部裁剪区域，只执行一次 Boolean Intersection，使用既有 Boolean 交点和网格规则，不采用开放裁剪的向零截断规则，不保证两个入口所有边界交点一致。本适配没有独立矩形专用算法的性能承诺。

窗口各轴接受 ±1_000_000_000（含端点），反向窗口报 InvalidInput；零宽或零高为合法空窗口，但仍验证限制、全部原始数量与坐标。原始额度只统计调用者 paths（含空路径及原始顶点），不统计内部矩形。

原始预检完成后才分配窗口或空结果。一个账本贯穿预检、窗口构造、扫描、清理和提取，注入账本的限制与历史用量保持权威，释放不退款。新增窗口收费为 11 个逻辑节点（4 个点、4 个槽、轮廓数组、操作数数组及其槽）和 6 单位构造工作；快捷空结果收费为 1 个容器节点和 1 单位工作。其余扫描存储和工作沿用引擎收费。窗口及原始参数错误标记 RectClipParameters，窗口构造标记 RectClipEvaluate，扫描和输出保留引擎阶段；原始校验保留路径／顶点索引，内部窗口不冒充原始输入。

## 开放折线窗口裁剪

`rect_clip_lines(rect : Bounds64, paths : Paths64, limits=)` 返回 `Result[Paths64, ClipError]`，当前仅在开发源码提供，已发布的 0.2.1 没有此入口。窗口按数学坐标使用 min_x、min_y、max_x、max_y，每个标量及输入点均接受 [-1000000000,1000000000]，包含边界。反向窗口报 InvalidInput；零宽、零高窗口是成功空结果，但仍检查原始数量和坐标。没有填充规则或孔洞层级。

## 开放序列

各路线独立处理。输入不会隐式闭合，显式末点返回首点则按真实线段处理。返回片段按路线和行进顺序排列，不反向、不旋转起点、不排序或跨路线拼接。普通共线中间点保留，连续重复点去除；单点、全重复点和孤立接触点不产生路径。输出数组独立拥有，输入不变，失败不返回部分结果。

例：窗口 [0,0]—[10,10]，路线 (-10,5)→(5,5)→(20,5)，结果为 (0,5)→(5,5)→(10,5)。路线 (-5,2)→(15,2)→(15,8)→(-5,8) 返回两个片段：(0,2)→(10,2)，随后 (10,8)→(0,8)。

## 贴边与数值

复用固定 Clipper2 2.0.1 的 RectClipLines64 状态转换，而非统一规定所有边界线段保留。以下窗口均为 [0,0]—[10,10]：

| 输入 | 输出 |
| --- | --- |
| (0,1)→(0,5)→(0,9) | 原样保留 |
| (-5,0)→(0,0)→(5,0)→(5,5) | (5,0)→(5,5) |
| (5,5)→(5,0)→(9,0) | 原样保留 |
| (0,0)→(10,0)→(10,10)→(0,10)→(0,0) | 原样保留，仍为开放序列 |
| (-5,5)→(0,0)→(5,-5) | 空；仅接触角点 |

一般线段交叉先以安全范围内的 Int64 叉积判断，再按 CLIPPER2_HI_PRECISION=0 的 Double 公式计算 t。t≤0 或 t≥1 时使用原端点，否则计算 a+t*(b-a) 并向零截断；端点／角点重合分支直接返回原点。这里的端点约束是上游公式的一部分，不是事后坐标钳制。没有 epsilon、侧边吸附或使用扫描投影／小数量化舍入。例如 (-2,0)→(2,1) 在 x=0 的 y=0.5 被截断为 0；负小数同样朝零转换。整数投影可能使极近边界的斜线成为水平片段，不保证无限精确的连续几何。

## 累计预算

公共入口新建一个 CallBudget；私有执行器可接收已有账本，后者的限制及历史计数保持权威。默认额度不变。释放不退款，每次分配前收费。点对象不可变，可共享已有输入点／角点，输出数组与输入不共享。

| 动作 | 逻辑节点 | 工作量 | 阶段／位置 |
| --- | ---: | ---: | --- |
| 原始路径数量与坐标预检 | 0 | 2×路径数＋原始顶点数 | RectClipParameters；保留原索引 |
| 窗口四个标量检查 | 0 | 固定参数检查，不计入输入额度 | RectClipParameters；None |
| 最外层输出数组（空结果也有） | 1 | 1 | RectClipOutput；None |
| 非空窗口四个角点＋点槽＋容器 | 9 | 4 | RectClipEvaluate；None |
| 每条路线的片段列表 | 1 | 1 | RectClipOutput；None |
| 读取顶点并作边界分类／推进 | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| 线段选择／交叉判定（至多四个精确叉积） | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| Double 求交 | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| 新建投影交点 | 1 | 1 | RectClipEvaluate；原路径／顶点 |
| 插入点前重复判定 | 0 | 每次 1 | RectClipOutput；None |
| 新片段容器＋列表槽＋首点槽 | 3 | 1 | RectClipOutput；None |
| 后续不重复点槽 | 1 | 1 | RectClipOutput；None |
| 最终片段有效性检查 | 0 | 每次 1 | RectClipOutput；None |
| 最终结果槽 | 1 | 1 | RectClipOutput；None |

原始数量预检完成前不建立输出。空路径仍占路径额度，重复点占原始顶点额度。零面积和无输入快捷分支只建立已计费的空输出，不建立角点或启动扫描；空输入收费 1 节点／1 工作量。窗口四个标量不冒充路径或顶点。输出存储错误没有可映射的原始位置时使用 None。
