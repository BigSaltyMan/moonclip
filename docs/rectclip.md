# 矩形窗口裁剪（0.3.0）

下述增量能力自 **0.3.0** 提供，见[发布记录](release-0.3.0.md)。0.3.1 只修正文档表述，不改变运行库行为或接口；带 Commit 编号的验收记录按原阶段解释。

## 窗口入口（自 0.3.0）

| 入口 | 窗口及坐标 | 输入解释 | 输出 |
|---|---|---|---|
| `rect_clip_lines` | Bounds64／整数 | 独立开放路线 | 有序开放片段 |
| `rect_clip_lines_d` | BoundsD／小数 | 共同量化的独立开放路线 | 有序小数开放片段 |
| `rect_clip_polygons` | Bounds64／整数 | 按 EvenOdd／NonZero 填充的闭合区域 | 平铺闭合区域，可含孔洞 |
| `rect_clip_polygons_d` | BoundsD／小数 | 同网格量化的闭合区域 | 平铺小数区域，可含孔洞 |
| `rect_clip_polygons_tree` | Bounds64／整数 | 按填充规则解释的闭合区域 | 最终整数孔洞树 |
| `rect_clip_polygons_tree_d` | BoundsD／小数 | 同网格量化的闭合区域 | 最终小数孔洞树 |

`rect_clip_lines_d` 默认 Precision=3（0—6），复用 BoundsD 校验与独立量化，再对所有路线共同开放量化并调用整数 `rect_clip_lines` 的私有执行器。结果保留片段顺序、方向和普通共线中间点，不隐式连接末首点，不跨路线拼接；显式返回起点按真实线段处理。空、单点、全重复路线和孤立点接触不形成有效片段。边界行为沿用整数入口，不承诺所有贴边线段一律保留。

小数窗口原始为空时仍验证全部输入与量化碰撞；原本有面积却量化塌缩时返回量化错误。窗口不占原始路径／顶点额度，也不加入路线碰撞表。数值经过半整数远离零量化、整数开放裁剪求交及向零截断、共同倍率解码三步，与闭合 Boolean 路线区分。全流程共享预算、失败不返回部分结果，输出与输入隔离；详见[小数契约](decimal.md)。库支持小数开放裁剪，网页窗口裁剪已支持整数与小数开放路线。

## 闭合区域孔洞树（自 0.3.0）

`rect_clip_polygons_tree`／`rect_clip_polygons_tree_d` 的窗口、填充规则和精度契约与对应平铺入口相同。默认 EvenOdd，也支持 NonZero；小数 Precision 默认 3、范围 0—6。内部只执行一次 Intersection，在最终提取回调中 `tree_build`，小数随后在同一回调中 `decimal_tree_output`；失败沿用扫描清理路径，不先提取平铺区域再公开求值。

层级属于裁剪后的真实区域，不沿用输入层级或顺序。完全位于窗口内的孔洞可以保留，切到窗口边缘的孔洞可能变成凹口，也可能出现多个根。例如外区域 [-2,-2]—[12,12] 与内轮廓 [3,3]—[7,7] 按 EvenOdd 求值：窗口 [0,0]—[10,10] 返回一个根和一个孔洞；窗口 [0,0]—[5,10] 返回正向八点外轮廓 (0,0)→(5,0)→(5,3)→(3,3)→(3,7)→(5,7)→(5,10)→(0,10)，没有孔洞孩子。根深度为 1，孔洞标记、方向和复制隔离沿用既有树类型；`to_paths()` 会丢失显式父子关系。

一次调用同账覆盖预检、窗口构造、扫描、树和小数转换。窗口不占原始路径／顶点额度，实际构造仍按既有 11 节点／6 工作收费。整数树费用使用 PolyTree，小数存储和解码使用 DecimalOutput，无原始对应位置为 None。传入账本的限制及历史消费保持权威，不退款、重置或提高默认预算。平铺入口仍使用原 output_extract 和原空结果 1 节点／1 工作，不承担树费用。

合法空窗口或空输入在必要校验后直接构造已计费空树，不分配无用平铺数组、不启动扫描；整数 `tree_empty` 收费 4 节点／1 工作，小数空树继续转换收费。原始空窗口仍检查闭合量化，窗口塌缩继续报错。小数树保留网格区域的整数拓扑，不重新判断浮点包含关系。旧参考目录没有逐项验证新树入口，Commit 43 的证据为 3 项定向测试；当前网页已接入整数／小数闭合窗口树，见[演示说明](demo.md)，对应库入口自 0.3.0 提供。

## 小数闭合区域窗口（自 0.3.0）

`BoundsD` 保存 min_x、min_y、max_x、max_y 四个不可变 Double，数据类型本身不验证。`rect_clip_polygons_d` 以相同 Precision 量化窗口和区域，再复用整数闭合裁剪，支持 EvenOdd／NonZero，返回小数平铺区域。默认精度 3，支持 0—6；另有树输出 `rect_clip_polygons_tree_d`；小数开放折线另用 `rect_clip_lines_d`。

窗口四个标量必须有限、在精度对应的原单位范围内且 min 不大于 max。原始零宽或零高窗口合法，但仍验证全部区域并执行闭合量化检查；原本有面积、量化后宽或高为零的窗口返回 QuantizationFailure，不静默吸附或扩宽。窗口是独立参数，不占原始路径额度，也不进入路径量化碰撞表。路径间碰撞检查不变，参数、存储、整数裁剪与小数解码共用预算，详见[小数契约](decimal.md)。

## 闭合区域窗口裁剪（自 0.3.0）

`rect_clip_polygons(rect, paths, fill_rule=, limits=)` 返回整数平铺闭合区域，默认 EvenOdd，也支持 NonZero。多条轮廓作为同一个填充区域求值，每条末点隐式连接首点，不要求重复首点；孔洞、重叠、自交及退化输入沿用 Boolean 语义。仅点或线接触不产生填充区域。输出可含孔洞，沿用 Boolean 的方向、共线清理和顺序约定，不保证保留原始顶点数、起点或轮廓排列。输入与输出隔离，失败不返回部分区域。

`rect_clip_lines` 解释独立开放路线并返回有序开放片段；本入口将窗口作为内部裁剪区域，只执行一次 Boolean Intersection，使用既有 Boolean 交点和网格规则，不采用开放裁剪的向零截断规则，不保证两个入口所有边界交点一致。本适配没有独立矩形专用算法的性能承诺。

窗口各轴接受 ±1_000_000_000（含端点），反向窗口报 InvalidInput；零宽或零高为合法空窗口，但仍验证限制、全部原始数量与坐标。原始额度只统计调用者 paths（含空路径及原始顶点），不统计内部矩形。

原始预检完成后才分配窗口或空结果。一个账本贯穿预检、窗口构造、扫描、清理和提取，注入账本的限制与历史用量保持权威，释放不退款。新增窗口收费为 11 个逻辑节点（4 个点、4 个槽、轮廓数组、操作数数组及其槽）和 6 单位构造工作；快捷空结果收费为 1 个容器节点和 1 单位工作。其余扫描存储和工作沿用引擎收费。窗口及原始参数错误标记 RectClipParameters，窗口构造标记 RectClipEvaluate，扫描和输出保留引擎阶段；原始校验保留路径／顶点索引，内部窗口不冒充原始输入。

## 开放折线窗口裁剪

`rect_clip_lines(rect : Bounds64, paths : Paths64, limits=)` 返回 `Result[Paths64, ClipError]`，自 0.3.0 提供，旧版 0.2.1 没有此入口。窗口按数学坐标使用 min_x、min_y、max_x、max_y，每个标量及输入点均接受 [-1000000000,1000000000]，包含边界。反向窗口报 InvalidInput；零宽、零高窗口是成功空结果，但仍检查原始数量和坐标。没有填充规则或孔洞层级。

## 开放序列

各路线独立处理。输入不会隐式闭合，显式末点返回首点则按真实线段处理。返回片段按路线和行进顺序排列，不反向、不旋转起点、不排序或跨路线拼接。普通共线中间点保留，连续重复点去除；单点、全重复点和孤立接触点不产生路径。输出数组独立拥有，输入不变，失败不返回部分结果。

例：窗口 [0,0]—[10,10]，路线 (-10,5)→(5,5)→(20,5)，结果为 (0,5)→(5,5)→(10,5)。路线 (-5,2)→(15,2)→(15,8)→(-5,8) 返回两个片段：(0,2)→(10,2)，随后 (10,8)→(0,8)。

## 贴边与数值

复用固定 Clipper2 2.0.1 的 RectClipLines64 状态转换，而非统一规定所有边界线段保留。以下窗口均为 [0,0]—[10,10]：

| 输入 | 输出 |
| --- | --- |
| (0,1)→(0,5)→(0,9) | 原样保留 |
| (-5,0)→(0,0)→(5,0)→(5,5) | (5,0)→(5,5) |
| (5,5)→(5,0)→(9,0) | 原样保留 |
| (0,0)→(10,0)→(10,10)→(0,10)→(0,0) | 原样保留，仍为开放序列 |
| (-5,5)→(0,0)→(5,-5) | 空；仅接触角点 |

一般线段交叉先以安全范围内的 Int64 叉积判断，再按 CLIPPER2_HI_PRECISION=0 的 Double 公式计算 t。t≤0 或 t≥1 时使用原端点，否则计算 a+t*(b-a) 并向零截断；端点／角点重合分支直接返回原点。这里的端点约束是上游公式的一部分，不是事后坐标钳制。没有 epsilon、侧边吸附或使用扫描投影／小数量化舍入。例如 (-2,0)→(2,1) 在 x=0 的 y=0.5 被截断为 0；负小数同样朝零转换。整数投影可能使极近边界的斜线成为水平片段，不保证无限精确的连续几何。

## 累计预算

公共入口新建一个 CallBudget；私有执行器可接收已有账本，后者的限制及历史计数保持权威。默认额度不变。释放不退款，每次分配前收费。点对象不可变，可共享已有输入点／角点，输出数组与输入不共享。

| 动作 | 逻辑节点 | 工作量 | 阶段／位置 |
| --- | ---: | ---: | --- |
| 原始路径数量与坐标预检 | 0 | 2×路径数＋原始顶点数 | RectClipParameters；保留原索引 |
| 窗口四个标量检查 | 0 | 固定参数检查，不计入输入额度 | RectClipParameters；None |
| 最外层输出数组（空结果也有） | 1 | 1 | RectClipOutput；None |
| 非空窗口四个角点＋点槽＋容器 | 9 | 4 | RectClipEvaluate；None |
| 每条路线的片段列表 | 1 | 1 | RectClipOutput；None |
| 读取顶点并作边界分类／推进 | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| 线段选择／交叉判定（至多四个精确叉积） | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| Double 求交 | 0 | 每次 1 | RectClipEvaluate；原路径／顶点 |
| 新建投影交点 | 1 | 1 | RectClipEvaluate；原路径／顶点 |
| 插入点前重复判定 | 0 | 每次 1 | RectClipOutput；None |
| 新片段容器＋列表槽＋首点槽 | 3 | 1 | RectClipOutput；None |
| 后续不重复点槽 | 1 | 1 | RectClipOutput；None |
| 最终片段有效性检查 | 0 | 每次 1 | RectClipOutput；None |
| 最终结果槽 | 1 | 1 | RectClipOutput；None |

原始数量预检完成前不建立输出。空路径仍占路径额度，重复点占原始顶点额度。零面积和无输入快捷分支只建立已计费的空输出，不建立角点或启动扫描；空输入收费 1 节点／1 工作量。窗口四个标量不冒充路径或顶点。输出存储错误没有可映射的原始位置时使用 None。

## 整数开放裁剪的历史参考与验证范围（Commit 26）

独立 v8 协议实际执行固定 C++ RectClipLines64，32 个新增案例按完整开放序列比较；生成的实际求值入口只链接输入和哈希，不链接参考预期。旧 1384 个案例及选择保持原样；当前总计 1416 个案例、2308 项能力检查，不把两目标或功能回归数量混加。

Commit 26 新增 47 项库测试（含 32 项参考），当时同 SHA Linux CI 完整通过 native 2370/2370、JS 2370/2370；本地只运行新增／受影响检查，证据链接见[增量验收索引](acceptance-incremental.md)。公开示例和候选包消费者直接断言完整坐标。Commit 26 当时不接小数、闭合面域裁剪、任意区域开放路径 Boolean、浏览器演示或新版本发布；开放输出必须按折线绘制。当前小数、闭合与网页能力以上方入口表及演示说明为准。
